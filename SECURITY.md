# Security and measurement integrity

Report security vulnerabilities privately through this repository's GitHub
"Report a vulnerability" form. Do not post credentials, personal training history,
Bluetooth identifiers, or exploitable security details in public issues.

For non-sensitive bugs, use a normal issue. Measurement-integrity reports should
include the gauge model, app version, and a minimal synthetic or redacted example.
Source releases on the default branch are the currently maintained version; older
snapshots may not receive backports. There is no guaranteed response time.
