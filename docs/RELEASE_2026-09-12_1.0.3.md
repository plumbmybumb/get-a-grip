# Get a Grip iOS 1.0.3 / Android 1.0.1 (9) release

Prepared 12 September 2026 from the canonical public checkout.

- iOS: 1.0.3 (7), app and widget.
- Android: 1.0.1 (9), existing closed alpha track.
- Store copy: `releases/1.0.3/`, English and French, separate platform notes.

## Changes

Fix the 20-pull ceiling with a tested 100-pull-per-side limit and bounded builder
previews. Preserve Android workouts and unsaved summary choices through light/dark
mode changes and Activity recreation. Add routine overviews with an Edit action,
History navigation from Last 14 days, the permanent long-rest presentation on both
platforms, and optional open-source community links in Settings.

The Android fix retains in-memory sessions across configuration changes; it does
not promise recovery after process termination. Recipients of shared routines with
more than 20 pulls need this updated version too. No BLE protocol, permissions,
database schema, or signing identity changes are included.

## Validation before packaging

- 687 iOS unit tests and 1,040 Android tests pass.
- Shared replay: 39 scenarios / 4,130 steps; 74 routine shares; 18 export scenarios.
- Focused UI checks cover appearance changes, partial work and unsaved summaries,
  typed 36/100 counts, overview navigation, English/French large text, and rest layout.
- The combined preview is installed and launched on the developer’s iPhone; the
  Android emulator is available for interactive use. This is not a new hardware
  validation claim for any gauge protocol.
- Independent source review found no release blocker. Signed artifact checks and
  store submission results are recorded after packaging.
