# Android max-hand fix — 7 September 2026

Android version **1.0.1 (4)** fixes the Maxes tab's measurement shortcut: users can
choose Both hands, Left hand, or Right hand directly on the measurement screen.
The hand remains visible and locked during a pull, and can be corrected before
saving. The chosen hand is carried through both direct saves and the max composer.

Failed direct saves retain the measurement for retry. Repeated save taps are
guarded, and navigation and hand changes are disabled while saving.

## Verification

- Full Android app and engine unit tests pass, including Compose UI regressions.
- Native 393 × 820 dp renders show the hand selector and Start without scrolling;
  the completed view also fits the graph, Try again and Use this max.

- Tests cover switching from Right to Left, active-pull lockout, correcting the

- Independent code review found no release blockers.
- Measurement engine, BLE pipeline, permissions, storage schema and iOS unchanged.
